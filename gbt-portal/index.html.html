⚙️ Firebase Setup Required

This portal uses Google Firebase for secure login and data storage — it's free and takes about 10 minutes to set up. Complete these steps once, then the portal is ready for you and your staff.

Step 1 — Create a Firebase project

Go to console.firebase.google.com and sign in with your Google account. Click Add project and name it gbt-portal. Disable Google Analytics when prompted.

Step 2 — Enable Authentication

In your project, go to Build → Authentication → Get started. Under Sign-in method, enable Email/Password. Then go to Users and add yourself: matthewcarr@greatbritishterroir.co.uk and a strong password. Add Millie's email for her access.

Step 3 — Create a Firestore database

Go to Build → Firestore Database → Create database. Choose Start in production mode and select europe-west2 (London) as your region.

Step 4 — Paste your Firebase config

Go to Project Settings → General → Your apps → Add app → Web. Register the app and copy the firebaseConfig object. Replace the placeholder config in the <script> section at the bottom of this HTML file with your values.

Step 5 — Set Firestore security rules

In Firestore → Rules, replace the existing rule with: allow read, write: if request.auth != null; — this ensures only logged-in users can access data.

Step 6 — Host on GitHub Pages or Netlify

Upload this single HTML file to GitHub Pages or Netlify (both free). You can then point your portal.greatbritishterroir.co.uk subdomain to it via your domain settings in Squarespace.
